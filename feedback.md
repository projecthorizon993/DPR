## Architecture Decisions

### 1. Post-capture filtering (NOT real-time)
- A13 chip too slow for live filtered video
- Capture RAW first, then process through Rust core after capture
- Viewfinder shows unfiltered live preview

### 2. Swift `CIColorCube` replaced by Rust C ABI
- Original Swift code used `CIColorCube` for color grading
- Removed entirely; replaced with Rust `process_photo` FFI calls
- No Core Image used in final pipeline for color processing

### 3. Rust FFI bridge (`CameraCoreBridge.swift`)
- `@_silgen_name` for C symbol matching
- Functions: `process_photo`, `fill_lut_for_style`, `fill_effect_params_for_style`, `apply_lut_3d`, `apply_color_matrix`, `apply_tone_curve`, `blend_watermark`
- Links against `libcamera_core.a` (aarch64-apple-ios)
- `libc` linked via `OTHER_LDFLAGS = "-lcamera_core"`
- `LIBRARY_SEARCH_PATHS` points to `rust-libs/`
- `HEADER_SEARCH_PATHS` points to `rust-core/src/`

### 4. Color profiles (reverse engineered from Android APKs)
Styles defined in `CameraStyle` enum:
- **Natural** (`lutStyleId=0`, `lutSize=0`): matrix-only, gamma 1.0
- **Xiaomi** (`lutStyleId=1`, `lutSize=17`): warm vivid Leica-inspired, matrix [1.10, 0.03, -0.05; -0.02, 1.05, 0.01; -0.03, -0.02, 1.07], gamma 1.04
- **OPPO** (`lutStyleId=2`, `lutSize=17`): cool crisp Hasselblad-inspired, matrix [1.03, -0.01, -0.04; 0.00, 1.07, -0.02; -0.04, -0.01, 1.05], gamma 1.02
- **Vivo** (`lutStyleId=3`, `lutSize=17`): soft portrait Zeiss-inspired, matrix [1.07, 0.01, -0.02; 0.01, 1.03, -0.03; -0.02, -0.04, 1.06], gamma 1.0

LUT data generated by Rust `fill_lut_for_style()` from `lut_data.rs` `StyleMatrix` + gamma curve.

### 5. UI: JustRaw SwiftUI (replacing original Xiaomi port)
The original Xiaomi MIUI port (`ContentView.swift` with 93dp shutter, mode pills, lens pills, amber #FFFFCE16) was **replaced** with JustRaw's complete SwiftUI UI:
- Full-bleed black camera preview
- Zoom slider (0.5×–10×), tap-to-focus, flash toggle, camera switch
- Bottom control bar with gallery, amber shutter (70px), style selector
- `StylePickerView` with Xiaomi-style amber accent + dark text selection
- `STYLE APPLIED` badge (top-right, amber capsule) when non-natural style active
- Dark mode throughout

### 6. Build pipeline (GitHub Actions)
Workflow: `.github/workflows/ios-build.yml`
1. Checkout repo
2. Install Xcode 15 toolchain
3. Install Rust stable + `aarch64-apple-ios` target
4. `cargo build --release --target aarch64-apple-ios` in `rust-core/`
5. Copy `libcamera_core.a` to `rust-libs/`
6. `xcodebuild archive` (Release, iphoneos, no code signing)
7. `xcodebuild -exportArchive` with manual signing, empty team ID
8. Upload IPA artifact: `camera-app-unsigned-ipa`

### 7. Installation on device
- Unsigned IPA requires **jailbroken iPhone 11 Pro Max**
- Install via **iLoader**
- Logs written to `Documents/Logs/` on device — retrieve via iTunes File Sharing or iLoader
- No App Store, no code signing, no provisioning profile

## Key Implementation Details

### `process_photo` FFI signature:
```c
int32_t process_photo(
    uint8_t* pixels, int32_t width, int32_t height, int32_t row_bytes,
    float* matrix, float* lut_data, int32_t lut_size,
    float gamma, float saturation, float vignette, float noise, uint32_t noise_seed,
    uint8_t* wm_pixels, int32_t wm_width, int32_t wm_height, int32_t wm_row_bytes,
    int32_t wm_offset_x, int32_t wm_offset_y, float wm_alpha
);
```

Pipeline order: color matrix → 3D LUT → tone curve → saturation → vignette → noise → watermark.

### Logging
All Rust filter functions call `rust_log_error()` on failure and `rust_log_info()` on success. Swift `Logger` class writes to `Documents/Logs/camera_app_<timestamp>.log`.

### Raw capture flow (JustRaw):
1. `CameraService.capturePhoto()` → `captureRAWWithZoomReset()` (resets zoom to 1.0x for RAW constraint)
2. `RAWProcessorService.processRAWToJPEG()` → CIRawFilter → crop → Rust FFI (if style != natural) → JPEG
3. `PhotoSaveService.saveDualPhotos()` → saves original RAW + processed JPEG to Photo Library

## Known Issues / TODO

### Build Issues
- GitHub Actions workflow uses Xcode 15 (`/Applications/Xcode_15.app`) — may need Xcode 16+ for iOS 18 SDK
- `libcamera_core.a` is a prebuilt binary (~4.9MB) — needs to be rebuilt if Rust source changes
- `CODE_SIGN_IDENTITY=""` and empty `DEVELOPMENT_TEAM` — unsigned build for iLoader

- JustRaw UI is not Xiaomi MIUI port — it's JustRaw's own design with style picker added
- Shutter button is white (JustRaw default), not amber `#FFFFCE16`
- No mode pills (PHOTO/VIDEO), no lens pills (0.5×/1×/2×), no recording indicator
- Only photo mode; no video recording
